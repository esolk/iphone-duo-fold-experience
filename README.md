# iDuo

一个纯 HTML5 / CSS / JavaScript / WebGL 的折叠手机交互体验，灵感来自 iPhone Duo 的磨砂开合过渡。

- 左右拖动手机开合；也可在设置中调节角度或播放动画。
- 选择本地照片或视频作为屏幕内容。媒体只在本机使用，不会上传。
- 双击手机或按 F 切换全屏；不支持原生全屏的浏览器会提示并使用沉浸模式。
- PC 普通窗口保留上下留白，移动设备使用沉浸布局，并提示横屏观看。
- 完全闭合和展开时画面清晰；转动时模糊从铰链向外缘增加。
- 支持视频播放/暂停、静音、铺满/完整适配、动画速度和玻璃效果切换。

## 使用

GitHub Pages 从 main 分支根目录发布 `index.html`，无需构建工具或依赖。

下载仓库后，直接打开 `duo-fold.html` 可离线使用。也可在仓库目录运行 `python -m http.server 8000`，然后访问本地端口 8000。

源码分别位于 `index.html`、`style.css`、`app.js` 和 `renderer.js`。修改源码后执行 `node build-standalone.cjs`，可重新生成离线单文件。

## 兼容与参考

需要支持 WebGL 的浏览器；照片和视频格式的解码能力由浏览器及操作系统决定。全屏行为取决于浏览器支持。当前检查包含桌面浏览器与横竖屏布局，尚未覆盖所有手机真机。

参考 [Apple iPhone Duo](https://www.apple.com/iphone-duo/)。本项目是独立编写的视觉近似实现，并非 Apple 官方代码或官方应用。机身尺寸、投影和模糊曲线经过视觉调校。
